# Domain

- **item** — one row in the browser: a name and the service that owns it.
- **page** — the window onto the items a single request renders: the selected
  rows, the total the store holds, and the cap the page was built with.
- **cap** — the `?limit=` ceiling on how many rows a page carries.
- **notice** — the trailing line telling the reader the cap withheld rows.
